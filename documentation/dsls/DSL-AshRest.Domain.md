# AshRest.Domain

The domain extension for AshRest, holding domain-wide options.

    use Ash.Domain, extensions: [AshRest.Domain]

    rest do
      error_handler MyApp.RestErrorHandler
    end

Use `AshRest.Domain.Info` to read the configuration.


## rest
Domain-wide options for the REST API.



### Examples
```
rest do
  error_handler MyApp.RestErrorHandler
  show_raised_errors? false
end

```




### Options

| Name | Type | Default | Docs |
|------|------|---------|------|
| [`error_handler`](#rest-error_handler){: #rest-error_handler } | `module \| mfa` |  | Transforms errors before they are sent to the client. Either a module implementing `AshRpc.ErrorHandler` (called as `handle_error(error, context)`), or `{module, function, args}` applied as `apply(module, function, [error, context \| args])`. Receives the ash_rpc error map and returns a map, or `nil` to drop the error. |
| [`show_raised_errors?`](#rest-show_raised_errors?){: #rest-show_raised_errors? } | `boolean` | `false` | Whether to show the details of *raised* errors to clients. When false they are replaced by a generic error. |
